# Project charter

## Research question
For a finite nonempty simple undirected tree, run the random-permutation greedy independent-set algorithm and compare its full output law with the uniform law on maximal independent sets.

## Scope
Primary programme:
- **A (conjecture):** exact uniformity occurs only for the one-vertex tree and the single edge.
- **B (construction target):** an explicit connected-tree sequence has positive bias tending to zero, with quantitative bounds.
- **C (optional extremal extension):** determine or bound the minimum positive bias among n-vertex trees.

A and B are to be judged for novelty and substance before proof work. C is not silently added merely to make the project sound stronger.

## Independence
This repository is separate from ProbStack — Random Stacking on Trees and from TreeStack. No conclusion from those projects is imported as evidence here.

## Integrity rules
Computational evidence is not proof. Literature search is not a uniqueness certificate. Lean formalisation will not begin until a complete informal theorem is proved and re-audited. No Palomar or arXiv status will be claimed before the corresponding external action is actually completed.
